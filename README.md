# GrowthKosh Website

Production-ready single-page marketing website built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` directly in a browser.

## Deploy
Upload the folder to Netlify, Vercel, GitHub Pages, cPanel/public_html, or any static hosting.

## Files
- `index.html` – page structure and SEO metadata
- `style.css` – responsive design and animations
- `script.js` – mobile menu, FAQ accordion, scroll reveal
- `logo.webp` – GrowthKosh wordmark
- `favicon.png` – browser icon
